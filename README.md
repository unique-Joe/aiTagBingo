# Tag 宾果 · 猜测辅助系统

一个纯前端静态网页，用于辅助“Tag 宾果”破冰游戏的猜测与绑定环节。

## 功能概览

- **5×5 Tag 表格**：支持逐格编辑、留空；选中任意格子后粘贴 Excel / WPS 表格数据，可自动按行列填充。
- **成员管理**：侧边栏添加、删除成员；支持按姓名搜索并点击选中；点击成员查看并编辑其自我描述。
- **生产环境名单**：一键载入预置名单（保留“梦拓-”前缀），快速开始正式活动。
- **风格一致的操作确认**：删除成员、清空全部、载入生产环境名单等关键操作均使用页面内部深色风格确认面板，不再调用原生 `alert/confirm`。
- **任务化 AI 分析**：单人分析与集群分析均作为独立任务加入队列，支持多个任务并发执行。
- **任务中心**：默认折叠为右侧边栏，点击展开；任务完成时会有全局 Toast 提示，侧边栏徽标同步显示运行/完成数量。
- **单人分析**：基于成员描述，由 AI 返回置信度最高的若干 Tag，在任务卡片中勾选后一键绑定。
- **集群分析**：多选或全选有描述的成员，批量与 Tag 混合匹配，每人返回 Top 3 候选；在任务卡片中按人勾选后批量绑定。
- **手动绑定**：
  - 点击 Tag 格子右上角的齿轮图标，可搜索成员姓名并添加绑定。
  - 也可以直接从左侧成员列表拖拽成员到右侧 Tag 方格完成绑定。
- **Tag 方格溢出控制**：单个格子绑定人员过多时，默认只显示前三个头像徽标，其余折叠为 `+N`。
- **深度思考开关**：顶部切换“深度思考”，按火山引擎文档使用 `thinking.type = enabled/disabled`，并适配深色模式。
- **数据持久化**：
  - 自动保存到浏览器 `localStorage`。
  - 同时写入浏览器 Origin Private File System 的 `data.json`，人名、描述等数据变更立即保存，无变更时每分钟也会快照一次。
  - 支持导出 / 导入 JSON 备份。

## 快速开始

1. 直接用浏览器打开 `index.html`（无需构建）。
2. 点击右上角“载入示例”可体验完整流程。
3. 点击“载入生产环境名单”可一键载入正式活动成员。
4. 在 5×5 表格中手动输入 Tag，或从 Excel 复制 5×5 区域后点击表格第一个格子粘贴。
5. 在左侧添加成员并填写描述。
6. 切换到“单人分析”或“集群分析”面板，点击 AI 分析按钮，分析任务会进入右侧折叠的“任务中心”。
7. 在任务卡片中查看候选结果、勾选确认后点击“绑定选中”。

## 火山引擎 API 配置

`app.js` 顶部已硬编码 API 信息：

```javascript
const VOLCANO_CONFIG = {
  endpoint: 'https://ark.cn-beijing.volces.com/api/v3/responses',
  apiKey: 'ark-b3d83d3b-6634-4bd4-88c2-4617bdc0e62e-a914a',
  model: 'doubao-seed-2-0-lite-260428',
};
```

- 界面不会显示 `model` 与 `apiKey`。
- 深度思考通过 `thinking.type` 控制：开启时传 `enabled`，关闭时传 `disabled`。当前模型默认开启深度思考。
- API 请求已设置 30 分钟超时，以兼容深度思考场景。

## 结构化输出

页面已开启火山引擎**结构化输出（beta）**，通过 `text.format.json_schema` 严格限定模型输出字段：

- **单人分析**：返回 `{ results: [{ index, confidence }] }`
- **集群分析**：返回 `{ results: [{ personId, suggestions: [{ index, confidence }] }] }`

因此提示词无需反复强调 JSON 格式，模型输出更稳定、字段不会缺失。

## 任务系统

所有 AI 分析都被抽象为任务：

- 任务运行期间卡片显示“分析中…”。
- 任务相互独立，可同时发起多个单人/集群分析。
- 分析完成后在任务卡片内查看结果，点击 Tag 候选卡片可切换勾选状态，再点击“绑定选中”完成绑定。
- 任务完成或失败时，页面右下角会弹出全局 Toast 提示。
- 可删除单个任务，或“清空已完成”任务。

## 数据文件 `data.json`

本应用使用浏览器的 **Origin Private File System (OPFS)** 自动写入 `data.json`：

- 每次人名、描述、Tag、绑定等数据变更后立即写入。
- 没有数据变更时，也会每分钟自动快照一次。
- `data.json` 保存在当前站点对应的私有文件系统中，页面刷新后仍可从该文件恢复数据。
- 如需在浏览器外部查看或备份，请使用“导出 JSON”功能。

## 拖拽绑定

左侧成员列表中的每个人员项均可拖拽：

- 按住人员项拖到右侧任意非空 Tag 方格上方，松开后即可绑定。
- 拖拽到空格子会提示“不能绑定到空 tag”。

## 如需更换 Key / Model

直接修改 `VOLCANO_CONFIG` 对象即可。若模型接口是 Chat Completions 格式而非 Responses 格式，解析逻辑 `_extractText` 也已做了兼容处理。

## 本地运行注意

由于浏览器 CORS 策略，直接双击 `index.html`（`file://` 协议）调用外部 API 可能会被拦截。建议通过本地 HTTP 服务器打开：

```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve .
```

然后在浏览器访问 `http://localhost:8080`。

## 安全提示

- 当前为自用本地小工具，Key 直接写死在前端。
- 如需部署到公网，请改由后端代理调用火山引擎 API，避免泄露密钥。
